# Privacy and editorial release checks

## Implemented behavior

- No GTM, Google Analytics, Meta script or tracking `noscript` beacon runs on first visit or after refusal. The old GTM container injected another Meta pixel and did not contain a GA measurement ID; it is removed. One existing Meta pixel is loaded only after explicit, versioned marketing consent. The previous generic `accepted` value is invalidated. Both choices are equally visible.
- The consent lasts at most 180 days and can be changed in the footer or privacy page. Withdrawal revokes the pixel, clears accessible optional cookies and reloads to unload previously executed code. Cross-tab withdrawals also stop it. Automatic Meta configuration and history tracking are disabled. Query/fragment URLs and purchase, administration, contact and interactive-tool pages do not load it. SPA navigation into a private flow unloads the already loaded pixel.
- reCAPTCHA, hosted fonts/images and infrastructure requests are separately described; rejecting marketing does not claim to eliminate required third-party services. The privacy page includes Groq, pseudonymous/public game data, order capabilities and actual retention behavior. It no longer promises unimplemented automatic 12-month deletion, 26-month analytics retention, or a universal five-year accounting period.
- The self-assessment preserves all original 35 questions. Its `habits-map-v3` response map runs only in React memory, without a request, browser-storage write or AI call. It groups answers by theme and their actual scale, separates unavailable answers, and uses no weights, reverse scoring, cross-question deductions or overall index. Switching modules preserves the current answers; reloading or leaving the page clears them. The server's previous v2 endpoint remains only for compatibility with the previously published frontend. Existing protected records are not deleted.
- The text analyzer separates untrusted input from system instructions, validates every category and explanation, and requires exact source-text evidence for positive categories. `language-signals-v3` returns all five categories, including explicit zeros. The new frontend presents possible signals, evidence and limitations without a numeric risk index. Invalid or incomplete output is a retryable error, never a reassuring zero. Legacy numeric fields remain in the server response for the previously published frontend. This does not perform fact-checking or establish author intent. The input and raw provider error are not logged or stored by the function. Groq's account-specific zero-retention configuration has not been verified.
- Focus now uses 12 local app prototypes with separate controls for grayscale, quiet example notifications and a pause of six social apps. It loads no game, provider, camera, location or real account data. The older game routes and protected data have not been deleted. Public texts no longer promise restored focus, hours saved or reduced anxiety. References distinguish research, conceptual frameworks and advocacy. Unrelated PMID 11548021 and PMC2825149 are removed; the re-identification link is corrected; references have usable author/year/title labels. Ego-depletion uncertainty, observational limits and lack of validation of the book are stated.
